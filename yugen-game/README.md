# Yugen: The World That Remembers

A story-driven 2D exploration game built with Phaser 4.

## Narrative direction

The protagonist wakes near a quiet village and is immediately told by a stranger: **“You came back.”** The protagonist has no memory of ever being there.

The central mystery is built around memory, repeated events, unreliable recollection, and a world that appears to remember people differently from how they remember themselves.

## First playable slice

- Explore a small village
- Move with WASD or arrow keys
- Collide with buildings and environmental obstacles
- Meet the Old Woman
- Advance the opening dialogue
- Trigger the first mystery conversation

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

The project is intentionally kept separate from the existing Yugen web applications in the repository so the game can evolve independently.
